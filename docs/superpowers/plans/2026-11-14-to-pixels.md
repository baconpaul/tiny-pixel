# to_pixels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A small C++20 library that draws antialiased, d-pad driven UIs (knob, slider, preset list, label) into a caller-owned XRGB8888 buffer with partial redraw, plus an OB-Xf-style example page rendered to PNGs.

**Architecture:** Three layers in one static library: `Canvas` (SDF-antialiased primitives into a non-owning `Surface`), `Font` (stb_truetype glyph cache), and a persistent `Component` tree under a `Root` that owns theme, focus, key repeat and a damage region with `buffer_age` history. Widgets sit on top. The example page is a separate static library shared by a PNG shot driver and the tests. Paul tries it as a CLAP later through `../dev_embedded_host`; the benchmark and live preview are dropped this round.

**Tech Stack:** C++20, CMake >= 3.21, vendored `stb_truetype.h` (library), `stb_image_write.h` and Catch2 v2 single header (tests/examples only).

**Spec:** `docs/superpowers/specs/2026-11-14-to-pixels-design.md`

## Global Constraints

- **No commits.** Paul manages commits. Never run `git add` or `git commit`; each task ends with a checkpoint where the tree builds and tests pass, uncommitted.
- C++20, `cmake_minimum_required(VERSION 3.21)`, static library `to_pixels`, alias `to_pixels::to_pixels`; works via `add_subdirectory` from a parent with PIC and hidden visibility.
- The `to_pixels` target links nothing but the C++ standard library and includes only `libs/stb/stb_truetype.h`. No SDL, freetype, harfbuzz, GL, platform SDK or JSON.
- No global or static mutable state anywhere in the library (constants are fine).
- stb implementations are compiled `static` (`STBTT_STATIC`, `STB_IMAGE_WRITE_STATIC`) so they cannot clash with another copy in OB-Xf.
- Must compile warning-clean with clang, gcc and MSVC: `-Wall -Wextra` (gcc/clang) or `/W4` (MSVC), PRIVATE to our targets only. MSVC cannot be built here; avoid GNU-only extensions, VLAs, `__attribute__`, and implicit narrowing.
- Pixel format: `uint32_t` `0xXXRRGGBB`; every written pixel has X = `0xFF`; X is never read. Rows are `strideBytes` apart.
- Namespace `tpx`. Headers in `include/to_pixels/`, sources in `src/`.
- Include guards `#ifndef TO_PIXELS_<FILE>_H` / `#define` / `#endif`, never `#pragma once`.
- Comments: one short line, lower case, why not what. No banners, no narration.
- Format with `.clang-format` copied from `/Users/paul/dev/small_devices/bacon_beats/libs/sst/sst-basic-blocks/.clang-format`.
- Shell: one command per Bash call, no `cd` prefixes, no `2>/dev/null`.
- Performance (from spec): on the RG40XX H, full redraw of the OB-Xf page < 33 ms, one knob/slider step < 2 ms. Not measured this round; still write the span fast paths Task 2 describes.

## Review Focus

1. A component destroyed while focused, or while its area is dirty: the root must drop focus and never touch the dead pointer (test in Task 6).
2. Host-set values outside 0..1 or NaN (`setValue` from a parameter change): clamp, NaN becomes the default, no callback (test in Task 7).
3. An empty preset list, or `setItems` shrinking below the selection: selection becomes -1 or clamps, Edit fires nothing, no crash (test in Task 8).
4. Shapes partly or wholly off-surface, negative coordinates, zero or negative sizes, a radius larger than half the rect: no out-of-bounds writes, radius clamped (test in Task 2).
5. Invalid UTF-8 or codepoints the font lacks, and text wider than its box: no crash, missing glyphs drawn as nothing but still advance, text clipped to the box (test in Task 3).

### Task 2: Canvas clip/translate stack and antialiased primitives

**Files:**
- Modify: `include/to_pixels/canvas.h`, `src/canvas.cpp`
- Create: `src/canvas_shapes.cpp`
- Test: `tests/canvas_test.cpp`

**Interfaces:**
- Consumes: Task 1 types.
- Produces (all on `Canvas`, coordinates in the current translated space; pixel centres at `x + 0.5`):
  - `void save(); void restore(); void translate(int dx, int dy); void clipTo(const Rect&); Rect clip() const;` (clip returned in current coordinates; `clipTo` intersects; initial clip = surface bounds).
  - `void fillRoundedRect(const RectF&, float radius, Color);`
  - `void fillRoundedRect(const RectF&, float radius, Color top, Color bottom);` vertical gradient, `t = (py + 0.5 - r.y) / r.h` clamped.
  - `void strokeRoundedRect(const RectF&, float radius, float width, Color);` stroke lies **inside** the rect.
  - `void fillCircle(PointF c, float r, Color); void strokeCircle(PointF c, float r, float width, Color);` (stroke centred on r)
  - `void strokeArc(PointF c, float r, float startRad, float endRad, float width, Color);` angles: 0 = 12 o'clock, positive clockwise on screen; requires `startRad <= endRad`, sweep clamped to 2π; round caps; stroke centred on r.
  - `void line(PointF a, PointF b, float width, Color);` round-capped capsule.

Coverage for every AA shape: `cov = clamp(0.5f - d, 0, 1)` with `d` the signed distance at the pixel centre, evaluated only over the shape's bounding box (grown by 1) intersected with the clip. Pixels with `d <= -0.5` across a whole span are written as solid spans (no per-pixel blend for opaque colours). Radius is clamped to `[0, min(w, h) / 2]`; non-positive sizes or widths draw nothing.

Distance functions (`canvas_shapes.cpp`):
- rounded rect, centre `c`, half size `hs`, radius `r`: `q = abs(p - c) - (hs - r); d = len(max(q, 0)) + min(max(q.x, q.y), 0) - r`.
- inside stroke of width `w`: `d = abs(sdRoundRect(p, hs - w/2, max(r - w/2, 0))) - w/2`.
- arc without per-pixel `atan2`: `a = (sin s, -cos s)`, `b = (sin e, -cos e)`, `cross(u, v) = u.x*v.y - u.y*v.x`. If sweep ≤ π: inside sector iff `cross(a, p) >= 0 && cross(p, b) >= 0`; else inside iff `!(cross(b, p) > 0 && cross(p, a) > 0)`. Inside: `d = abs(len(p) - r) - w/2`; outside: `d = min(len(p - r*a), len(p - r*b)) - w/2`.
- capsule: distance to segment minus `w/2`.

static void press(tpx::Root &r, tpx::Input k)
{
    r.input({k, true});

TEST_CASE("partial renders match a full render after a session", "[obxf]")
{
    ObxfPage page;
    tpx::Image live(ObxfPage::width, ObxfPage::height);
    page.root().render(live.surface(), 0);
    auto step = [&] { page.root().render(live.surface(), 1); };
    press(page.root(), tpx::Input::Down); step();
    press(page.root(), tpx::Input::Down); step();
    press(page.root(), tpx::Input::Edit); step();
    press(page.root(), tpx::Input::Right); step();
    page.root().input({tpx::Input::Edit, true});
    for (int i = 0; i < 5; ++i) { press(page.root(), tpx::Input::Right); step(); }
    page.root().input({tpx::Input::Edit, false}); step();
    press(page.root(), tpx::Input::Down); step();

    tpx::Image fresh(ObxfPage::width, ObxfPage::height);
    page.root().render(fresh.surface(), 0);
    for (int y = 0; y < ObxfPage::height; ++y)
        for (int x = 0; x < ObxfPage::width; ++x)
            REQUIRE(live.at(x, y) == fresh.at(x, y));
}

TEST_CASE("double buffering with buffer age 2 stays correct", "[obxf]")
{
    // a host swapping two buffers: each holds the frame from two renders ago
    ObxfPage page;
    tpx::Image bufs[2]{{640, 480}, {640, 480}};
    int n = 0;
    auto frame = [&] {
        page.root().render(bufs[n % 2].surface(), n < 2 ? 0 : 2);
        ++n;
    };
    frame();
    frame();
    page.root().setFocus(&page.knob(0));
    frame();
    page.root().input({tpx::Input::Edit, true});
    for (int i = 0; i < 6; ++i)
    {
        page.root().input({tpx::Input::Up, true});
        page.root().input({tpx::Input::Up, false});
        frame();
    }
    tpx::Image fresh(640, 480);
    page.root().render(fresh.surface(), 0);
    const auto &last = bufs[(n - 1) % 2];
    for (int y = 0; y < 480; ++y)
        for (int x = 0; x < 640; ++x)
            REQUIRE(last.at(x, y) == fresh.at(x, y));
}

TEST_CASE("choosing a preset and turning cutoff reach the params", "[obxf]")

    page.root().input({tpx::Input::Right, true});
